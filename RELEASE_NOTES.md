# Portfolio 0.2.0 — installable downloads

Early release with six purpose-built ZIPs. No account, email signup, license key, or external service required.

## Downloads

- WordPress plugin: upload in Plugins → Add New → Upload Plugin. WordPress 6.4+, PHP 8.1+.
- cPanel / static website: local visual editor, explicit content.js save, JSON backup/import, ready-to-upload HTML/CSS/JS.
- Webflow, Wix, Squarespace, HTML embed kits: editable website, code generator, and platform instructions. Host over HTTPS and embed; these are not native apps.

## Included

Project galleries/filters, case-study narratives, implementation details, evidence images/links, architecture list, outcomes/provenance, responsive/print styles, fictional samples, and MIT/GPL notices.

WordPress includes a separate post type, scoped assets, nonce/capability-protected story saves/admin actions, draft-only import, duplicate protection, public JSON export, and read-only public REST projection. Existing MU code is not bundled or migrated.

## Validation

Publishing is gated on contract/link/unsafe-input checks, JavaScript/PHP syntax, ZIP layouts/licenses/checksums, repeatable local builds, browser editing/export/reopen, and a cross-origin iframe. The exact plugin ZIP is installed in disposable WordPress for publication, permission, sanitization, gallery/REST, contract, and HTTP checks.

Inspect the workflow result for this tag. This is not an independent security audit or full compatibility certification.

## Limits

No live builder-account publication tests, native platform CMS integration, hosting, email collection, analytics, or payments. Static rendering requires JavaScript; editor saves downloads, not server files. WP structured-meta revisions, Gutenberg grid block, legacy migration, broad theme/multisite/version matrix, and Plugin Check/directory submission remain incomplete. Public JSON export caps at 1,000 and moves no binary media; keep full backups.

See README and docs/downloads.md for setup.
