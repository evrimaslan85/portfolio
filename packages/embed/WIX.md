# Wix embed package

1. Edit the projects using `hosted-portfolio/editor.html`, then download/replace `content.js`.
2. Upload `hosted-portfolio` to your own HTTPS hosting.
3. In Wix, choose **Add → Embed Code → Embed a Site** and enter your hosted `embed.html` HTTPS address. You can also use the iframe code generated by the included `make-embed.html`.
4. Resize the element for desktop and mobile, preview, and publish.

The hosted page must use HTTPS and allow framing. This ZIP is not installed through the Wix App Market and does not create native Wix CMS items. Changes are made with the local editor and uploaded to the hosting that serves the embedded page.

Official instructions: https://dev.wix.com/docs/develop-websites/articles/wix-editor-elements/other-elements/html-i-frame-element/embedding-a-site-in-an-html-i-frame-element

Browser rendering and the generated iframe are tested locally. No live Wix account was used to verify publication in this release.
